🚀 Favicon 缓存功能

智能图标缓存系统，提升 98% 的加载速度

✨ 核心特性

  • 双层缓存架构（内存 + 持久化）
  • 自动过期管理（7天有效期）
  • LRU 淘汰策略（最多100个图标）
  • 异步加载，不阻塞界面
  • 启动时自动清理过期条目

📊 性能对比

首次加载: ~500ms (需要网络请求) 后续加载: ~10ms (直接从缓存读取) 10个域名: 从 ~5s 降至 ~100ms

🔧 使用方法

缓存系统会自动工作，无需手动配置。如需清理缓存：

// 在浏览器控制台执行 chrome.storage.local.remove('faviconCache');
💡 提示： 每次打开扩展弹窗时，图标会优先从缓存加载，大幅减少网络请求和等待时间。缓存会在7天后自动过期，确保图标始终保持最新。
